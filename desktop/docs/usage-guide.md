# CTB 地形切片桌面端 —— 使用教程

桌面端把 ctb 四个命令行工具包装为图形表单，无需记忆参数；同机还可使用
纯命令行包，命令行用法见同目录 [`cli-usage.md`](./cli-usage.md)。

## 一、启动与运行时检查

1. 安装版从开始菜单/桌面快捷方式启动；绿色版双击 `ctb-desktop.exe`。
2. 启动后查看左下角运行时状态，显示「运行时就绪：4 个工具」即正常，
   同时展示 `GDAL_DATA` 的真实生效路径。
3. 若显示工具数为 0，进入「运行时设置」页，选择含 `ctb-tile.exe` 的
   目录（如 `E:\terrain\ctb\tools\ctb-cesium-jin`）后保存，配置持久化。
4. 绿色版放在中文目录时，首次启动自动把 `gdaldata` 部署到
   `C:\ProgramData\ctb-desktop\gdaldata`，无需手工处理。

## 二、界面布局

左侧导航五个页签，对应四个工具加一个设置页：

| 页签 | 对应命令 | 作用 |
| --- | --- | --- |
| 地形切片 | `ctb-tile` | DEM/栅格切 Terrain 或 Quantized Mesh 瓦片 |
| 瓦片信息 | `ctb-info` | 查看瓦片高度、子瓦片、水陆类型 |
| 瓦片导出 | `ctb-export` | 按层级/行列号导出单个瓦片 |
| 覆盖范围 | `ctb-extents` | 输出各层级覆盖范围 GeoJSON |
| 运行时设置 | — | 自定义 ctb 运行时目录 |

每个工具页结构一致：参数表单 → 底部「命令预览」→「开始执行/取消/重置」
→ 日志输出区。

## 三、典型操作：切片（ctb-tile）

1. 切到「地形切片」页。
2. 输入文件点「浏览」选择 DEM 数据源（`.tif` 等 GDAL 可打开的格式）；
   输出目录点「浏览」选择成果目录。
3. 按需要设置表单选项：
   - 输出格式：`Mesh`（Quantized Mesh，Cesium 常用）或 `Terrain`。
   - 剖面：默认 `geodetic`，Web 墨卡托场景选 `mercator`。
   - 起始/结束层级：起始层级数字更大（从高往低切），结束层级最小为 0。
   - 重采样：DEM 一般用 `nearest` 或默认 `average`。
   - 线程数：默认等于 CPU 核数，内存紧张时调小。
   - 勾选 `Cesium Friendly`（对应 `-C`）可补齐缺失根瓦片，推荐常勾。
4. 观察底部「命令预览」，确认拼出的命令与预期一致，例如：

   ```
   ctb-tile -o D:\terrain\export\srtm_dem -f Mesh -s 10 -e 0 -r nearest -c 4 -C D:\terrain\demdata\srtm.tif
   ```

5. 点「开始执行」，日志区实时滚动 ctb 的标准输出/错误；点「取消」可
   中止当前任务（同一时间只允许运行一个任务，避免并发写同一输出目录）。
6. 任务结束后日志区显示成功/失败状态与退出码。

## 四、其他三个工具

- **瓦片信息**：选择一个 `.terrain` 文件，按需勾选显示高度栅格
  （`-e`）、隐藏子瓦片（`-c`）、隐藏类型（`-t`），执行后在日志区查看。
- **瓦片导出**：填输入瓦片、层级 `z`、行列号 `x/y` 和输出文件路径，
  对应 `ctb-export -i ... -z ... -x ... -y ... -o ...`。
- **覆盖范围**：选择输入数据集与输出目录，可选剖面、瓦片尺寸、层级范围，
  产出各层级的 GeoJSON 覆盖范围文件。

## 五、实用机制

- **表单持久化**：所有表单值自动保存在浏览器本地存储，下次打开自动恢复。
- **命令预览**：任何参数改动都会实时刷新等价命令行，可与手工教程对照。
- **运行时优先级**：设置页自定义目录 → exe 同级 `ctb-runtime`（绿色版）→
  安装包内置资源 → 开发期工作区回退目录。
- **DLL 与工作目录**：Rust 侧自动把进程工作目录锁定到运行时目录并注入
  `GDAL_DATA`，保证 `ctb.dll/gdal202.dll/zlib.dll` 正确加载。

## 六、常见问题

- **启动后工具数为 0**：到「运行时设置」指定正确的 ctb 目录并保存。
- **日志报 `gcs.csv` / EPSG 错误**：`GDAL_DATA` 路径含中文；GUI 版应自动
  部署到 ProgramData，若仍报错检查该目录是否可写，或改用纯英文安装路径。
- **输出目录里有旧成果**：勾选「断点续跑」（`-R`）跳过已存在瓦片，
  或清空输出目录后重切。
- **根瓦片 `0\0\0.terrain` 缺失**：勾选 Cesium Friendly 重切，并核对
  `layer.json` 的 `available` 首项（详见 `cli-usage.md` 第五节）。
- **任务无法启动**：确认上一个任务已结束（按钮恢复为「开始执行」）。
